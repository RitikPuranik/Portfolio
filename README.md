## ✦ About this portfolio

This repository contains my personal developer portfolio, built to present my work, technical skills, education, experience, and certifications in one place.

The visual direction combines a forest-green and warm-cream palette with golden accents, expressive typography, and motion-led interactions. The goal is to keep the experience distinctive without getting in the way of the work itself.

### What's inside

- **Editorial hero experience** with oversized typography and responsive layouts.
- **About section** introducing my interests and approach to building software.
- **Resume section** with education, internship experience, certifications, skill groups, and a downloadable PDF.
- **Project showcase** with descriptions, technology tags, live demos, and source links where available.
- **Contact section** to make it easy to connect.
- **Motion and interaction** using GSAP, ScrollTrigger, and Lenis.
- **Responsive design** for desktop and smaller screens.

## 🚀 Featured projects

### 1. ANNDATA
**Agricultural Intelligence & Digital Marketplace**

An agricultural platform connecting farmers, FPOs, buyers, warehouses, and transporters. Features include mandi-price insights, AI-assisted price forecasting, sell-versus-store decision support, buyer matching, negotiation, logistics workflows, shipment tracking, and selected WhatsApp-based farmer-assistant features.

**Stack:** Next.js, React, TypeScript, Node.js, Express, PostgreSQL, Prisma, Redis, AI forecasting, WhatsApp Business API.

- **Live:** [anndata-jet.vercel.app](https://anndata-jet.vercel.app/)
- **Source:** [RitikPuranik/Anndata](https://github.com/RitikPuranik/Anndata)

### 2. DevDrop
**AI Website Generation · Marketplace · Deployment**

A platform for discovering and selling website templates, including auctions and seller payouts. Its AI Studio generates and edits React/Vite websites from prompts and assets, supports previews and AI-assisted repairs, and works alongside a queued deployment flow for Vercel and Render.

**Stack:** React, Vite, Node.js, Express, MongoDB, Supabase, BullMQ, Redis, Gemini, Groq, Playwright, Socket.IO, Razorpay.

- **Live:** [dev-drop-gamma.vercel.app](https://dev-drop-gamma.vercel.app/)
- **Source:** [RitikPuranik/DevDrop](https://github.com/RitikPuranik/DevDrop)

### 3. CodeWave Solution
**Online Course Enrollment Platform**

An education platform for online and offline coding courses. My internship work involved building and managing the platform, including responsive interfaces and backend APIs.

**Stack:** React, Vite, Material UI, Tailwind CSS, Node.js, Express, MongoDB, Supabase, Google OAuth, Socket.IO.

- **Live:** [codewavesolution.in](https://codewavesolution.in)

### 4. FoodGram
**Social Food Discovery & Sharing**

A full-stack social platform focused on discovering food and local vendors through visual content. It includes social interactions such as following, saved posts, comments, and media uploads, with JWT-based authentication.

**Stack:** React, Vite, Tailwind CSS, Framer Motion, Node.js, Express, MongoDB, ImageKit, Multer.

- **Live:** [food-app-nine-liard.vercel.app](https://food-app-nine-liard.vercel.app/)
- **Source:** [RitikPuranik/FoodGram](https://github.com/RitikPuranik/FoodGram)

## 💻 Run locally

### Prerequisites

- Node.js and npm
- Git

### Setup

```bash
git clone https://github.com/RitikPuranik/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Vite prints a local development URL in the terminal after the server starts.

### Available scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the local development server |
| `npm run build` | Type-check the project and create a production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
